### Task 1: Frontend scaffold, tooling, CI

**Files:**
- Create: `frontend/` (from the Vite template), `frontend/src/App.test.tsx`, `frontend/src/test/setup.ts`
- Create: `.github/workflows/frontend.yml`
- Modify: `frontend/vite.config.ts`, `frontend/eslint.config.js`, `frontend/package.json`, `frontend/tsconfig.app.json`, `AGENTS.md`

**Interfaces:**
- Consumes: nothing. This plan is independent of the backend plans.
- Produces: `npm run dev|build|lint|format:check|test|gen:api` in `frontend/`; `@/` import alias for `frontend/src`; shadcn/ui components under `frontend/src/components/ui/`; build output in `backend/src/mlops_agents/web/`.

- [ ] **Step 1: Scaffold**

Run from the repo root:
```bash
npm create vite@7 frontend -- --template react-ts
cd frontend
npm install react@19 react-dom@19
npm install react-router@7 @tanstack/react-query@5 openapi-fetch@0.17 react-markdown@10 remark-gfm@4
npm install -D typescript@~5.9 vite@7 @vitejs/plugin-react tailwindcss@4 @tailwindcss/vite@4 vitest@3 jsdom @testing-library/react@16 @testing-library/jest-dom @testing-library/user-event prettier@3 eslint@9 typescript-eslint eslint-config-prettier openapi-typescript@7 @types/node@22
```

- [ ] **Step 2: Configure Vite, Tailwind and Vitest** — replace `frontend/vite.config.ts`:

```ts
import path from "node:path";
import tailwindcss from "@tailwindcss/vite";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vitest/config";

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: { alias: { "@": path.resolve(__dirname, "src") } },
  server: { proxy: { "/api": "http://127.0.0.1:8765" } },
  build: {
    outDir: path.resolve(__dirname, "../backend/src/mlops_agents/web"),
    emptyOutDir: true,
  },
  test: {
    environment: "jsdom",
    setupFiles: ["./src/test/setup.ts"],
    exclude: ["e2e/**", "node_modules/**"],
  },
});
```

Create `frontend/src/test/setup.ts`:

```ts
import "@testing-library/jest-dom/vitest";
```

Replace `frontend/src/index.css` with:

```css
@import "tailwindcss";
```

In `frontend/tsconfig.app.json` add to `compilerOptions`: `"baseUrl": "."`, `"paths": { "@/*": ["./src/*"] }`, `"noUncheckedIndexedAccess": true`, `"types": ["vite/client", "vitest/globals"]`. Keep `"strict": true`.

- [ ] **Step 3: Initialize shadcn/ui**

```bash
npx shadcn@4 init
npx shadcn@4 add button input label card dialog dropdown-menu select table badge tabs sonner scroll-area collapsible separator alert textarea tooltip
```
If `init` asks: style "new-york", base color "neutral", CSS variables "yes". It writes `components.json`, `src/lib/utils.ts` and `src/components/ui/*`.

- [ ] **Step 4: ESLint strict + Prettier** — replace `frontend/eslint.config.js`:

```js
import js from "@eslint/js";
import prettier from "eslint-config-prettier";
import reactHooks from "eslint-plugin-react-hooks";
import reactRefresh from "eslint-plugin-react-refresh";
import globals from "globals";
import tseslint from "typescript-eslint";

export default tseslint.config(
  { ignores: ["dist", "src/api/schema.d.ts", "src/components/ui/**", "playwright-report", "test-results"] },
  {
    extends: [js.configs.recommended, ...tseslint.configs.strictTypeChecked],
    files: ["**/*.{ts,tsx}"],
    languageOptions: {
      globals: globals.browser,
      parserOptions: { projectService: true, tsconfigRootDir: import.meta.dirname },
    },
    plugins: { "react-hooks": reactHooks, "react-refresh": reactRefresh },
    rules: {
      ...reactHooks.configs.recommended.rules,
      "react-refresh/only-export-components": ["warn", { allowConstantExport: true }],
      "@typescript-eslint/no-explicit-any": "error",
    },
  },
  prettier,
);
```

`src/components/ui/**` is generated by shadcn and kept as generated; our own code is linted.

Create `frontend/.prettierrc.json`: `{ "printWidth": 100 }` and `frontend/.prettierignore`:
```
dist
src/api/schema.d.ts
src/components/ui
openapi.json
```

In `frontend/package.json` set `"scripts"`:

```json
{
  "dev": "vite",
  "build": "tsc -b && vite build",
  "lint": "eslint .",
  "format": "prettier --write .",
  "format:check": "prettier --check .",
  "test": "vitest run",
  "gen:api": "openapi-typescript openapi.json -o src/api/schema.d.ts"
}
```

- [ ] **Step 5: Write the failing test** `frontend/src/App.test.tsx`

```tsx
import { render, screen } from "@testing-library/react";

test("shows the app name", () => {
```

Run: `cd frontend && npm test`
Expected: FAIL (`App` is a default export in the template, or the heading is missing).

- [ ] **Step 7: Run all frontend checks**

Run: `cd frontend && npm test && npm run lint && npm run format:check && npm run build`
Expected: 1 test passes; lint and format clean; build writes `backend/src/mlops_agents/web/index.html`.

- [ ] **Step 8: Add the frontend CI workflow** — create `.github/workflows/frontend.yml`:

```yaml
name: Frontend

on:
  push:
    branches: ["main", "plan/**"]
  pull_request:

jobs:
  frontend:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: frontend
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
          cache-dependency-path: frontend/package-lock.json
      - run: npm ci
      - run: npm run lint
      - run: npm run format:check
      - run: npm test
      - run: npm run build
```

```markdown
## Frontend commands

Run from `frontend/`:
- Install: `npm ci`
- Dev server with hot reload (proxies `/api` to the backend on port 8765): `npm run dev`
- Tests: `npm test` (one file: `npx vitest run src/path/File.test.tsx`)
- Lint and format: `npm run lint`, `npm run format:check`
- Build into the backend package: `npm run build`
- Regenerate API types after the backend API changes: `npm run gen:api`
```
